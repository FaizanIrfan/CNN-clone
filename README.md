# CNN Homepage Clone

This is a static clone of the CNN homepage created using **HTML** and **CSS** only. It replicates the layout, design style, and basic structure of the official CNN website as a front-end learning project.

## 🚀 Features

- Header with logo and navigation
- News content sections
- Styled buttons, links, and images
- Clean, organized HTML & CSS structure

## 🛠️ Built With

- HTML5
- CSS3 (no frameworks)
